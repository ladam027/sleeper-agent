How to get the most out of Sleeper Agent

Short version: leave chat on Auto, pin your core facts, and let the budgets do their job.

1. Teach it who you are (once)

Tell it your name, job, city, goals, projects and preferences in one message. Then go to Memory and pin the 5–10 facts it needs constantly. A single "Owner profile" memory works best. Pinned facts ride along with every message for about $0.00004 each and save a paid search on every question.

2. Leave chat on Auto

Auto sends simple things ("what's my name?", "remind me what I said about X") to Quick (Haiku 4.5). Planning, research, writing, analysis and long messages go to the Orchestrator (Opus 5.5). If Quick is out of its depth it hands off by itself. Each reply shows which model answered and what it cost.

3. One conversation, many models

In Auto, both agents share one conversation, so the orchestrator sees what you told Quick and the other way round. Pick an agent by name only to force it. History is capped at the last 20 messages to keep costs flat, and anything older lives in memory.

Model prices

Per million tokens. A typical short chat turn is 2–6k tokens in, 100–500 out.

"Cached" is the price when the same prompt prefix was sent in the last 5 minutes. Back-to-back messages are much cheaper than spread-out ones.

Keeping costs to a minimum

  • Batch your asks. One message with three requests beats three messages, because each turn re-sends the conversation.
  • Be specific. "Draft 3 Etsy titles for a minimalist fox print" is cheaper than a vague ask plus two rounds of clarification.
  • Start fresh topics fresh. Long unrelated history makes every reply cost more. Save what matters to memory and move on.
  • Pin carefully. Pin stable facts only. Editing a pinned memory resets the cache, so the next message costs a bit more.
  • Watch the Costs tab. If a day spikes, the Activity feed shows which agent and step did it.
  • Budgets are hard stops. Each agent has a daily cap and there's a global cap in Settings. Agents stop at the cap instead of overspending, and one runaway loop is cut off after 8 steps.
  • Phrases that stay cheap on Auto: questions, lookups, "remember that…", quick edits.
  • Phrases that trigger Opus: plan, research, analyze, build, draft, compare, strategy, business, invest, marketing, website, or anything over ~500 characters.
  • Force a model any time with the picker above the chat.

Memory vs Vault

Ask yourself: does the agent need to know it, or only use it?

  • Memory (agent reads it, and it's sent to Anthropic): name, job, city, birth year, goals, projects, which bank or broker you use.
  • Vault (never leaves this machine): passwords, API keys, card numbers, account numbers, SSN, full address, exact date of birth.
  • Don't vault something you want the agent to know. Vault values are replaced with {{secret:name}} everywhere before sending, including in memory.
  • Card numbers and SSNs are stripped from chat automatically even if you never saved them.

Safety controls

  • Approvals: risky actions (creating agents now; sending, posting, paying and trading later) wait on the Overview until you approve them.
  • Kill stops one agent mid-task. Restart clears a stuck one. The red Kill switch blocks every agent from calling the API.
  • The dashboard only listens on this computer. Phone access comes in Build 2 via Tailscale.
  • Your chats, memory and vault live in data/agent.db. Updates never replace it, and it's backed up on every start.
